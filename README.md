# 🧾 Vega Business CMS

A custom Content Management System (CMS) built with **Laravel** for **Vega Business** — designed to manage website content, news, team, services, and more with ease.

## 🌐 Project Overview

Vega Business CMS is a backend management system tailored for business websites. It offers secure, user-friendly admin interfaces to update and manage dynamic content without writing code.

## 🚀 Features

- User Authentication (Login/Logout)
- Manage Pages (About, Contact, Services, etc.)
- Media/File Upload
- Dynamic Menu Management
- Responsive Admin Dashboard

## 🛠️ Tech Stack

- **Framework:** Laravel 12.11.1
- **Database:** MySQL
- **Frontend:** Blade templating, Bootstrap 5
- **Auth:** Laravel 
- **File Upload:** Laravel File Storage
